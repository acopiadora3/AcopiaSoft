# AcopiaSoft

Sistema móvil y web para la gestión eficiente del centro de acopio de leche, optimizando el registro de productores, pesaje diario y trazabilidad de la calidad.

## Idea del Proyecto

 AcopiaSoft nace como una solución integral para digitalizar la recolección y acopio de leche en áreas rurales. Actualmente, la captura de datos (litros entregados, densidad, acidez y pagos) se realiza de forma manual en papel, lo que genera errores de cálculo, pérdida de información y falta de transparencia con los ganaderos/productores.

### Módulo Móvil (Desarrollo de Aplicaciones Móviles)
* **Registro de Entregas en Campo:** Permitir a los acopiadores/recolectores registrar la cantidad de litros recibidos e ingresar los parámetros de control de calidad desde un teléfono o tablet.
* **Modo Offline/Sincronización:** Capacidad para almacenar registros localmente cuando no hay cobertura de red en zonas rurales y sincronizar automáticamente al detectar conexión.
* **Consulta para Ganaderos:** Interfaz para que los productores vean su historial de entregas cotidianas y el acumulado a cobrar en la quincena/mes.

### Marco Metodológico (Ingeniería de Software 1)
* **Ingeniería de Requisitos:** Definición y modelado de historias de usuario, casos de uso y matriz de trazabilidad.
* **Arquitectura de Software:** Implementación de arquitectura cliente-servidor mediante API REST con patrones de diseño móvil (MVC/MVVM).
* **Calidad y Pruebas:** Diseño de casos de prueba unitarios e integración para garantizar la consistencia en el cálculo de pagos y métricas de calidad.
